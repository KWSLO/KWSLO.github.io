我是花满渚

花满渚，酒满瓯。
——（我的昵称来源于此，或许可能只是我某天突然觉得这个名字挺有意境）

“花满渚”这个名字，显然不是真名（雾）。

它更像是一个漂浮在网络世界里的小小印记。取自诗句 “花满渚，酒满瓯”，几分江南烟雨，几分闲云野鹤。我还是很喜欢这个名字带来的感觉的。它有花、有水、有一点自由，也有一点不确定。

毕竟，人生天地间，忽如远行客。在浩瀚互联网中，能有一个地方留下自己的痕迹，也算是一件挺浪漫的事情吧。

可以公开的信息

基本信息

  • 出生于 2006 年
  • 星座：金牛座
  • 当前状态：一名仍在求学中的大学生，目前大二

小时候倒是挺挺早就开始打各种游戏的，比如：Minecraft，生化危机 4，泰拉瑞亚等等

回头看看，那些游戏或许并不只是游戏。它们更像是一扇扇窗口，让我第一次接触到计算机的广阔天地，愿意为了下载某个游戏在整个互联网上翻箱倒柜 ꒰ঌ(˶ˆᗜˆ˵)໒꒱

在这其中，我学会了简单的信息检索方法，一些基本的计算机知识，当然，最重要的是能让我接触到了更广阔的世界，能了解世界各地。

大概是这样一种感慨吧:

本想在沙滩拾贝，不曾想，我却拾起了整片海洋的涛声

至于学习方面，只能说：

运气不错，努力也没有完全浪费。

中学时期成绩一直还算不错，算不上什么天选之子，但也没有辜负自己的时间。当然，我觉得我的中学最开心的时候就是和同学一起踢毽子，一起去足球场上踢球，一起在校园里散步，畅谈人生。倒也没有辜负了这段光阴。

到了大学，我的大学虽然谈不上惊艳四座，不过姑且也算是小有名气？（小声）

不过人生本就是一场长途旅行。

路漫漫其修远兮，吾将上下而求索。

慢一点也没关系，重要的是一直向前走。

兴趣爱好

音乐

音乐大概是生活中不可缺少的一部分。纯音乐、二次元音乐、流行歌曲等等，我都有所涉猎。

有时候喜欢安静地听一首钢琴曲，有时候也会循环某些奇奇怪怪但十分上头的歌曲。

除此之外，也姑且算是会一点点口琴。说来也好笑，我之前买了一把 Hohner sp20

本来的计划倒是：

我要吹出自己喜欢的歌曲！

然而现实：

等等……为什么别人吹起来这么简单，我这里怎么还缺半音？

后来才知道，很多歌曲如果想要吹，还得专门学习压音。

人生也大抵如此吧，本以为是轻松支线任务，结果发现隐藏Boss已经刷新。

（笑）

计算机

毫无疑问，我喜欢计算机。从美化桌面，上网冲浪，再到各种奇奇怪怪的小项目。

有时候花几个小时解决一个小问题，最后发现：

解决问题本身，就是最大的乐趣
————当然，配环境不在此列 (-_-;)💢

计算机世界有一种独特的魅力，你输入一串代码，它回应你的想法。你创造一个页面，它便成为互联网中的一个小角落。

这大概就是所谓的：

把想法变成现实。

游戏

这个应该不用多说。毕竟童年很多快乐，就是从游戏开始的。

游戏不仅仅是娱乐。它们承载了许多记忆，也影响了我看待世界的方式。

探索未知，解决问题，挑战困难。这些体验，或许也悄悄塑造了现在的我。

建站缘由

为什么会有这个网站？

其实原因很简单：想找一个地方记录一些东西

如果只是单纯地把代码、笔记、文章丢到 GitHub 仓库里，总感觉少了一点什么。

像是写了一封信，却没有地址。

于是思来想去：

不如自己搭个网站？

然后，一个小小的个人博客就诞生了。

从域名，到部署；
从主题，到样式；
从文章，到各种奇奇怪怪的小功能。

一点一点折腾。

很有极客精神，不是吗？

（听说成为计算机糕手的第一步，就是搭建个人博客。）

当然，这句话是我瞎编的。

但是……

万一呢？

关于网站

网站托管

目前网站托管于：

GitHub Pages

俗称万能的：

github.io

免费、稳定、方便。

对于个人博客来说，简直就是非常舒服的选择。

相关服务

Hexo

静态博客生成框架。简单来说，它负责把 Markdown 文件转换成漂亮的网页。

Butterfly

本站使用的 Hexo 主题。

一个美观、功能丰富，同时又拥有较高可定制性的主题。

各种：

  • 动画效果
  • 页面布局
  • 标签功能
  • 评论系统
  • 个性化配置

都可以慢慢调整。

当然，调整过程中也会伴随着：

为什么改一下 CSS，整个页面炸了？

这种经典事件。

Cloudflare

网站相关服务之一。

负责：

  • DNS
  • CDN 加速
  • 安全防护

让这个漂浮在互联网中的小站，可以更加稳定地运行。

Obsidian

个人知识管理工具。

用于记录：

  • 学习笔记
  • 灵感想法
  • 技术资料
  • 日常碎片

有时候，一个念头可能只是一颗小小的种子。

记录下来，说不定某一天：

忽如一夜春风来，千树万树梨花开。

最后

这里没有什么宏大的目标。

只是希望，在时间流逝之后，回头还能看到：

啊，原来我曾经在这里留下过一些东西。

互联网很大。

个人很小。

但哪怕只是一粒尘埃，也可以拥有自己的坐标。

愿：

花满渚，酒满瓯。

愿：

此间少年，终有所成。

感谢你的到来。
