背景

观前思考：为什么 Transformer 能在短短几年内，彻底取代 RNN 和 LSTM，成为 NLP 乃至整个 AI 领域的基石？

在Transformer之前，NLP领域多用RNN或LSTM来做序列建模和文本生成。RNN和LSTM都是循环结构，它们维护一个不断更新的隐藏状态，将历史信息压缩其中，并根据这个状态和当前输入来预测下一个词。但这样的结构带来了两个突出的问题。

首先是训练速度问题。由于RNN和LSTM必须按时间步依次计算：算完 $h_t−1$ 才能算 $h_t$​ 。整个序列是高度串行化的，无法像矩阵运算那样充分并行。这使得它们很难利用现代GPU大规模并行的优势，训练速度受到严重制约。

其次是长距离依赖问题。在自然文本中，相距很远的词句之间往往存在语义关联。然而RNN的信息必须沿时间步逐步传递，在处理长序列时极易出现梯度消失或梯度爆炸。LSTM通过门控机制大幅缓解了这一问题，但信息仍须逐步传递，在足够长的序列上依然会出现衰减，难以真正捕捉远距离的依赖关系。

以上两个问题，前者意味着RNN和LSTM训练慢，后者意味着它们甚至很难训练好。在这种背景下，2017年，Vaswani等人提出了Transformer（“Attention Is All You Need”）。它彻底抛弃了循环结构，转而使用自注意力机制：所有位置的Query、Key、Value可以同时计算，整个序列一把送入模型做矩阵运算，天然适合大规模并行。这正是如今成千上万张GPU组成的算力集群得以发挥作用的前提。与此同时，自注意力让文本中任意两个位置都能直接交互信息，路径长度仅为O(1)，从根本上改变了长距离依赖的传递方式。

当然，去掉循环结构也意味着模型不再天然感知词序，因此Transformer需要额外引入位置编码来告诉模型谁在前、谁在后。此外，自注意力的计算复杂度随序列长度呈O(n²)增长，这在超长序列场景下会带来新的瓶颈，也催生了后来FlashAttention、线性注意力等一系列优化工作。

尽管如此，Transformer相比RNN和LSTM的优势是压倒性的。它迅速取代了循环结构，成为NLP领域的主流架构。后来的GPT系列取其decoder部分做自回归生成，BERT取其encoder部分做双向理解，而当下的大语言模型，几乎都是在这一架构基础上演化而来的。

Transformer 发展与演变

原始论文里，Transformer是Encoder-Decoder型的结构，但随着时间推移，业界逐渐提出了三个流派，分别是Encoder-only型，Encoder-Decoder型（范式统一），以及Decoder-only型。三种流派的代表分别是BERT，T5，和GPT。到了如今这个节点，想必大家也不难猜到最后是哪种流派成为绝对主流——就是以GPT为代表的Decoder-only型大模型。

下面我们来深入了解一下原始Transformer以及三种变体。

原始 Transformer

如图1所示，原始Transformer是由若干个Encoder和若干个Decoder组成。以及里面用到了三种Attention，分别是 Multi-Head Self Attention，Masked Multi-Head Self Attention，以及 Cross Attention。


图1. 原始Transformer架构

Encoder

Encoder由两个核心子层组成，分别是Multi-Head Self-Attention以及Feed-Forward Network（FFN）。它接收token序列的表示，输出与原序列维度一致的表示序列，该序列随后会被送入下一层Encoder，或在最顶层作为Decoder中Cross-Attention的Key和Value来源。

原始Transformer将N=6个结构相同的Encoder层依次堆叠。每一层的输入和输出维度都是 $d_{model}=512$，这一设计使得层与层之间可以无缝衔接，也方便通过增加层数来扩展模型容量。

  • 残差连接（Residual Connection）：将输入 $x$ 直接加到子层输出上。这使得梯度可以绕过子层直接回传，有效缓解了深层网络中的梯度消失问题，也让6层乃至更多层的堆叠成为可能。

Decoder

该部分由三个核心子层组成，分别是 Masked Multi-Head Self-Attention、Cross Attention 以及 Feed-Forward Network（FFN）。相比Encoder，Decoder多了一个Cross Attention子层，用于从原文提取信息。同样地，原始Transformer将 N=6 个Decoder层依次堆叠，每层的输入输出维度均为 $d_{model}$=512。

在推理（生成）阶段，Decoder的工作方式是自回归的：它接收已经生成的目标序列 $y{≤n}$，经过三个子层处理后，输出下一个位置的概率分布，采样得到 $y{n+1}$​，再拼接到输入序列中，循环往复，直到生成结束符。而在训练阶段，目标序列会通过Teacher Forcing一次性全部输入，模型并行地学习每个位置的预测，无需逐步生成。

与Encoder相同，Decoder中每个子层也都包裹着残差连接和层归一化：

因果掩码自注意力（Masked Multi-Head Self-Attention）

在生成任务中，位置 $i$ 的token只能看到自己和之前的信息，不能偷看未来的内容。为此，我们需要对Self-Attention施加因果掩码（Causal Mask）。

其中 $M{ij}$ = $0$（当 $j≤i$），$M{ij}$ = $-\infty$（当 $j>i$）。这样，经过softmax后，未来位置的注意力权重趋近于零，模型自然无法获取尚未生成的信息。

三种变体

随着NLP任务需求的多样化，原始Transformer的Encoder-Decoder结构逐渐演化出三个主要流派。它们分别针对理解、序列到序列和生成任务进行了特化。

Encoder-only（专注于理解）

该变体的代表是谷歌在2018年发布的 BERT模型。相比于原始Transformer，该变体删去了Decoder部分，仅保留Encoder部分。

由于没有因果掩码的限制，Encoder-only模型在计算Self-Attention时，每个token都能同时关注到序列中所有的其他token（即双向注意力）。这种全局视野使其在自然语言理解任务上表现出极强的优势。

在预训练阶段，BERT主要采用掩码语言建模（Masked Language Modeling, MLM），即随机遮住输入序列中的一些token（如[MASK]），让模型根据上下文来预测这些被遮住的词。这种训练方式赋予了模型深厚的语义表征能力。预训练完成后，只需在顶层添加一个简单的线性层进行微调（Fine-tuning），就能很好地应用于文本分类、情感分析、命名实体识别（信息抽取）和句子相似度等下游任务。


图2. Encoder-only架构（以BERT模型为例）

Encoder-Decoder（范式统一与序列到序列）

该变体保留了原始Transformer的完整结构，代表模型包括谷歌在2019年发布的 T5模型 以及早期的BART等。

T5模型做了一件极具影响力的事情：将所有NLP任务都转化为“Text-to-Text”（文本到文本）的格式。这意味着，无论是翻译、文本摘要、问答，还是传统的文本分类任务，模型的输入都是一段文本提示（Prompt），输出也是一段文本。


图3. Encoder-Decoder架构（以T5模型为例）

例如，做情感分类时，输入不再是单纯的句子，而是 classify: This movie is great，输出则是 positive。


图4. Text-to-Text 范式统一

这种架构的优势在于：Encoder负责双向地深刻理解源文本，Decoder负责自回归地生成目标文本。通过统一的Text-to-Text框架，所有任务都可以使用相同的损失函数和训练代码，极大地简化了多任务学习的工程复杂度。

Decoder-only（生成式大模型的绝对主流）

简单介绍

该变体最出名的代表是 OpenAI 的 GPT 系列（Generative Pre-trained Transformer）。它的成功彻底改变了当今 AI 的发展轨迹。


图5. Decoder-only架构（以GPT为例）

从结构上看，该架构大刀阔斧地去掉了 Encoder 和 Cross-Attention，仅保留了带有因果掩码的 Masked Self-Attention 和 FFN。它的工作原理非常纯粹：输入一段 token 序列，模型只能看到前面的词，然后自回归地预测下一个 token。

为什么看似残缺、且只能单向注意力的架构，最终打败了另外两个流派，成为当今大模型的绝对主流？核心原因有以下几点：

  1. 统一的生成范式与 Scaling Law（缩放定律）：Decoder-only 天然契合自回归的语言生成过程。研究发现，随着模型参数量、数据量和计算量的增加，Decoder-only 模型的性能会呈现出可预测的幂律增长。这使得工业界可以坚定地将算力投入到扩大模型规模上，从而力大砖飞。
  2. 涌现能力（Emergent Abilities）与上下文学习：当模型规模突破一定阈值后，它展现出了惊人的能力，即无需更新参数，只需在输入中提供几个示例（Few-shot Prompting），模型就能理解并执行全新的任务。这种能力是 Encoder-only 难以做到的。
  3. 极佳的预训练并行性：虽然生成（推理）阶段是串行的，但在海量的预训练阶段，由于整个长文本序列可以同时输入，并利用因果掩码进行高度并行的矩阵运算，这使得在成千上万张 GPU 集群上训练巨量参数的模型成为可能。
  4. 交互方式的天然契合：人类的自然交流方式本质上就是对话和文本生成。Decoder-only 架构天然适合构建像 ChatGPT 这样的对话式智能体。

简而言之，Decoder-only 架构用极其简单的结构，配合海量的数据和算力，统一了几乎所有的 NLP 任务流程，成为了当下大语言模型不可动摇的基石。

下面来深入了解Decoer-only模型

1. 端到端数据流：一次推理的完整旅程

Decoder-only 架构将模型简化为一条极其纯粹的单向数据流。以一次实际的 LLM 推理为例，我们可以跟踪数据从输入到输出的完整生命周期：

假设用户输入：”ABCDEFG”

  • Step 1: 分词与嵌入 (Tokenization & Embedding)
    文本首先经过 Tokenizer 转化为 Token ID 序列（如 [1234, 567, 89, 2345, 678]）。随后，通过查表操作（Token Embedding），将这些离散的 ID 映射为连续的稠密向量，得到形状为 $(seq_len, d_{model})$ 的输入矩阵 $X$。

  • Step 2: 穿越 Decoder Block 堆叠
    矩阵 $X$ 依次穿过 $L$ 层结构完全相同的 Decoder Block。在每一层中，数据会经历：
    RMSNorm -> Masked Self-Attention (含 RoPE 位置编码) -> 残差连接 -> RMSNorm -> FFN (如 SwiGLU) -> 残差连接。
    经过 $L$ 层处理后，输出矩阵 $X_{final}$ 的维度依然严格保持为 (seq_len, d_model)。

    ps. 此处LayerNorm放在最前的做法是PreNorm的方法。

     即 $Output = X + SubLayer(LayerNorm(X))$

  • Step 3: 输出映射 (LM Head)
    $X{final}$ 经过最后一次 RMSNorm 归一化后，送入语言模型头（LM Head）。这是一个线性层，将 $d{model}$ 维的隐藏状态映射回词表大小 $V$，得到 Logits 矩阵 $(seq_len, V)$。

  • Step 4: 概率计算与采样
    我们只提取 Logits 矩阵中最后一个时间步（即最后一个 token 的位置）的向量，通过 Softmax 函数将其转化为词表上的概率分布。接着，根据设定的采样策略（如 Greedy、Top-p、Temperature 等）从概率分布中采样出下一个 Token。

  • Step 5: 自回归循环
    将新生成的 Token 拼接到原输入序列的末尾，重新送入模型，重复上述过程，直到生成结束符（EOS）或达到最大长度限制。

将现代 Decoder-only 架构与原始的 Encoder-Decoder Transformer 并排对比，可以清晰地看到前者在工程实现和理论设计上做了哪些减法与进化：

Transformer 组件详解

在宏观了解了 Transformer 的架构演变后，我们需要深入其内部，拆解构成大模型的”原子级”组件。无论是 2017 年的原始 Transformer，还是当今如日中天的 LLaMA、GPT 系列，其核心都由几个关键模块拼装而成。以下来深入解析这些组件

1. Attention (注意力机制)

基本原理

注意力机制是 Transformer 的灵魂。它打破了 RNN 的时间步限制，让序列中的每个词都能直接”看到”并”关注”其他相关的词。

输入向量通过三个不同的线性变换矩阵，映射为 Query（查询）、Key（键）和 Value（值）：

  • Query (Q)：代表”我正在寻找什么信息”。
  • Key (K)：代表”我有什么特征，可以被别人检索到”。
  • Value (V)：代表”我实际包含的具体内容”。

（2）GQA（Grouped-Query Attention）

  • MQA（Multi-Query Attention）：所有 Q 头共享一组 K、V 头。$n_{kv} = 1$

（3）Flash Attention

Flash Attention 不改变注意力的数学定义，而是从IO 感知（IO-Aware） 的角度优化了计算过程。

标准 Attention 的计算流程会产生大量中间矩阵（$S \times S$ 的注意力分数矩阵），这些矩阵需要在 GPU 的 HBM（高带宽显存）和 SRAM（片上缓存）之间反复读写，IO 成为瓶颈。

Flash Attention 的核心策略：

  • 分块计算（Tiling）：将 Q、K、V 分成小块（block），在 SRAM 中完成 $\text{softmax}(QK^T/\sqrt{d_k})V$ 的计算，避免将 $S \times S$ 的完整矩阵写回 HBM。
  • 在线 Softmax（Online Softmax）：传统 softmax 需要两遍扫描（先求最大值，再求归一化），Flash Attention 通过维护运行时的最大值和分母，实现单遍计算。
  • 重计算（Recomputation）：前向传播时不保存注意力矩阵，反向传播时重新计算，用计算换内存。

最终效果可以做到将 Attention 的显存复杂度从 $O(S^2)$ 降到 $O(S)$

2. Position Embedding (位置编码)

基本原理

Self-Attention 的计算本质上是集合运算，具有排列不变性（Permutation Invariant）。这意味着如果没有位置信息，”我打他”和”他打我”在模型看来是完全一样的。因此，必须显式地注入位置信息。

3. LayerNorm (层归一化)

基本原理

深度网络在训练时，每一层输入的分布会随着前面层参数的更新而不断改变（内部协变量偏移）。LayerNorm 通过将数据拉回到均值为 0、方差为 1 的标准分布，稳定了训练过程，允许使用更大的学习率，加速收敛。

标准 LayerNorm 公式：

其中：

  • $\mu = \frac{1}{d}\sum_{i=1}^d x_i$（均值）
  • $\sigma^2 = \frac{1}{d}\sum_{i=1}^d (x_i - \mu)^2$（方差）
  • $\gamma, \beta \in \mathbb{R}^d$ 是可学习的缩放和偏移参数
  • $\epsilon$ 是防止除零的小常数

参数量：每层 $2 \times d{model}$ 个参数（$\gamma$ 和 $\beta$ 各 $d{model}$ 个）。以 $d_{model}=4096$ 为例，每层 8192 个参数，几乎可以忽略不计。

（1）Post-Norm → Pre-Norm

为什么 Pre-Norm 更好？

第一，出于训练稳定性的考量。在Post-Norm 中，残差路径上的信号被归一化层截断，梯度回传时需要经过归一化层的 Jacobian，深层网络中容易梯度不稳定。Pre-Norm 保留了完整的残差路径（$x$ 直接加到输出上），梯度可以无损回传。

第二是可堆叠深度。Post-Norm 通常只能稳定训练 12-24 层，而 Pre-Norm 可以轻松堆叠 80-128 层甚至更多。

那代价是什么呢？代价是Pre-Norm 的表达能力理论上略弱于 Post-Norm（因为归一化在子层之前，子层看到的输入被压缩了），但在足够深的网络中这个差距可以忽略。

（2）LayerNorm → RMSNorm

RMSNorm（Root Mean Square Normalization）由张钹院士团队提出，核心思想是：去掉减去均值的操作，只做除以均方根。

与标准 LayerNorm 对比：

LayerNorm RMSNorm
计算均值 $\mu$ 需要 不需要
计算方差 $\sigma^2$ 需要 用均方根替代
可学习偏移 $\beta$ 有 没有
可学习缩放 $\gamma$ 有 有
参数量 $2d$ $d$
计算量 较高 减少约 30-50%

为什么去掉均值也可以？

实验表明，减去均值（中心化）对最终效果的贡献微乎其微。真正起作用的是缩放操作，其防止某些维度的数值过大或过小。RMSNorm 只保留缩放，去掉了中心化，既简化了计算，又保持了训练稳定性。

参数量：每层 $d{model}$ 个参数（只有 $\gamma$）。以 $d{model}=4096$ 为例，每层 4096 个参数。

5. FFN (前馈神经网络)

基本原理

如果说 Attention 负责的是词与词之间的信息交互与路由，那么 FFN 负责的就是单个词内部信息的非线性加工与记忆。

学术界普遍认为，FFN 层充当了 Transformer 的知识记忆库（Key-Value Memory）。模型在预训练阶段学到的世界知识，很大一部分被记录在了 FFN 的权重矩阵中。

原始结构

即：先通过 $W1$ 升维（通常 $d{ff} = 4d{model}$），经 ReLU 激活，再通过 $W_2$ 降维回 $d{model}$。

为什么 SwiGLU 更好？

首先是引入了门控机制，$\text{SiLU}(xW{gate})$ 充当了一个软开关，可以动态地放大或抑制 $xW{up}$ 中的不同维度，比固定的 ReLU 截断更灵活。

其次是具有平滑性，SiLU/GELU 是平滑函数，处处可导，不像 ReLU 在 0 点有尖角，有利于优化。

同时在 PaLM、LLaMA 等大规模实验中，SwiGLU 相比 ReLU 带来了约 1-2% 的困惑度（perplexity）下降，这在大规模预训练中是显著的提升。

结语

回顾整篇文章，我们从一个简单的问题出发：为什么 Transformer 能在短短几年内，彻底取代 RNN 和 LSTM，成为 NLP 乃至整个 AI 领域的基石？

答案其实并不复杂。Transformer 的成功，本质上是三个简单的胜利：

  • 结构简单：抛弃了循环和递归，只留下注意力和前馈网络。没有花哨的门控，没有复杂的记忆单元，有的只是矩阵乘法和 softmax。
  • 范式简单：一个统一的预测下一个 token目标，就能覆盖翻译、摘要、问答、推理、代码生成……几乎所有你能想到的语言任务。不再需要为每个任务设计专门的模型结构。
  • 扩展简单：由于天然适配并行计算，Transformer 可以毫无障碍地吃下更多的数据、更多的参数、更多的算力。Scaling Law 告诉我们，只要把模型做大、数据做多、算力堆够，智能就会涌现。

从组件层面看，我们拆解了 Attention 如何让每个 token 与全局对话，RoPE 如何优雅地编码相对位置，RMSNorm 和 Pre-Norm 如何让深层的网络稳定训练，SwiGLU 如何让 FFN 成为模型的知识库，以及残差连接如何为梯度铺设一条信息高速公路。每一个组件都不复杂，但当它们被组装成 DecoderBlock，再被堆叠 32 层、80 层、128 层时，量变引发了质变，一个只会预测下一个词的统计模型，开始展现出理解、推理、甚至创造的能力。

这或许是深度学习最迷人也最令人困惑的地方：我们完全理解每一个零件的工作原理，却仍然无法完全解释它们组合在一起后涌现出的智能。

当然，Transformer 不会是终点。我们已经看到了它的局限：$O(n^2)$ 的注意力复杂度限制了超长上下文，自回归生成天然无法并行导致推理成本居高不下，纯粹的下一词预测范式在复杂规划和多步推理上仍有短板。Mamba 等状态空间模型、扩散语言模型、混合架构等方向正在被积极探索。但无论未来的架构叫什么名字，Transformer 所确立的核心范式：用注意力机制建模全局依赖、用大规模预训练获取通用能力、用自回归生成完成人机交互，大概率会作为底层思想，继续影响下一代模型的设计。

2017 年，八位作者用一篇论文告诉我们：Attention Is All You Need。

几年后的今天，这句话的含义已经远远超出了技术本身。它更像是一个隐喻：在通往通用人工智能的道路上，我们最需要的，或许不是更复杂的结构，而是对注意力，对信息的选择、聚焦与关联的更深刻的理解。

希望这篇文章，能帮你建立起对 Transformer 从宏观到微观的完整认知。如果你读到了这里，感谢你的耐心。
