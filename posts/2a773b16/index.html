博客搭建之基础

发表于2026-08-05|更新于2026-08-09|Misc
|总字数:1.4k|阅读时长:5分钟|浏览量:

说在前面

作为本网站的第一篇post，还是很有意义的。当然也是回顾一下我搭建个人博客的方法。

如果你只是想简单搭建个博客用来放文章，那么看完这篇教程就足矣创建一个还算美观且实用性不错的网站

如果你不仅仅满足于套用现成的主题，想深度定制自己的个人网站样式，那么可以把这系列的文章都看完(当然截止2026.8.8，这个系列还是只有这一篇文章

概览

大致讲解一下搭建网站的流程


图1. 个人博客搭建流程图（简要提及所用技术和服务)

我们通过 Github Pages 来为网站提供托管，使用 Cloudflare 免费版来为网站提供 DNS 解析等服务，接着用 Hexo + Butterfly 来生成美观的博客页面。大致流程就是如此。下面来详细解说

流程

P1.域名购买

购买一个自己的域名很不错，除非你想每次看到一个丑陋的 github.io(

域名购买这方面可以去阿里云，腾讯云等等服务商购买。比如我们这里演示阿里云:


图2. 在阿里云查询想要购买的域名。如图所示，价格还是很便宜的

当然，在国内服务商购买的域名得实名认证才能正式启用，认证时间大概是30min-1h左右。如果不想实名认证也可以去一些国外服务商处购买域名。


图3. 实名认证完域名才能启用

选一个自己心仪的域名就可以开始下一步了！

P4 接入 Cloudflare

如果没有购买个人域名，可以直接跳过这个部分

首先是去 Cloudflare 上注册账号，进入 Workers&Pages，点击创建应用，然后选择github，接着选择我们刚刚创建的 username.github.io仓库，接下来一直确认就行。

部署完成之后，可看到 Cloudflare 给我们的域名 xx.pages.dev

然后在你本地的博客文件夹，进入source文件夹，新建文件 CNAME ，不要有后缀，里面放入你的域名。运行 hexo 三件套

进入刚刚部署完成的项目的 Custom domain，选择新建 Custom domain，然后填入你的域名

tips.记得先在cloudflare里解析一下你的域名，不然你域名的DNS服务还是你购买域名的服务商提供

最后确保记录是这样


图7. DNS记录
